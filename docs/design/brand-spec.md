# peruwonderstours — inventario de marca preservado

Logo real: `apps/web/public/logo.png`. No se redibuja ni se sustituye.
Fotografía del catálogo: `data/seed/tours.json`, destinos y manifiesto legado; las páginas consumen `CatalogImage` con `next/image`. Medios originales de la API no están en Git.
Fuentes locales: `packages/ui/src/fonts` (Geist, Geist Mono y Fraunces, con licencias).
Tokens: `packages/ui/src/tokens.css`, `tokens.ts` y `theme.css`.
Sistema: `design-system/peru-wonders-tours/MASTER.md` y overrides de páginas.

Azul Titicaca para navegación, terracota para acción principal, piedra como fondo, estados semánticos para éxito/aviso/error. Se preservan idioma es/en, contenido real y contratos de reservas y autenticación.

La actualización de web/admin se describe en `design-system/peru-wonders-tours/ui-refresh.md`. Las capturas visuales no están acreditadas por la limitación del navegador integrado; no se inventan evidencias.
