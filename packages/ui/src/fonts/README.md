# Fuentes locales

Se mantienen Geist, Geist Mono y Fraunces del sistema de diseño. Archivos variables
latinos (incluyen los caracteres de español e inglés) obtenidos de
`@fontsource-variable/geist`, `@fontsource-variable/geist-mono` y
`@fontsource-variable/fraunces`, versión 5.3.0. Fraunces usa el archivo de ejes completos.

Las licencias SIL Open Font License acompañan cada familia. Next las optimiza y
sirve desde el propio sitio; compilar la web ya no necesita descargar Google Fonts.
